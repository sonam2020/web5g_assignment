
# Web5G Assignment

A static website developed using HTML, CSS, and JavaScript.

## 🌐 Live Preview

🔗 **[View Live Website](https://sonam2020.github.io/web5g_assignment/)**

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Actions
- GitHub Pages

## 📂 Project Structure

```text
web5g_assignment/
├── index.html
├── style.css
├── script.js
├── README.md
└── .github/
    └── workflows/
        └── deploy.yml
```

## 🚀 Deployment

The website is deployed using GitHub Pages with GitHub Actions.

Every time new changes are pushed to the `main` branch, GitHub Actions automatically triggers the deployment workflow and updates the live website.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sonam2020/web5g_assignment.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
